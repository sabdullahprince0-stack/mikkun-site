# MIKKUN portfolio

Production source for [mikkun.site](https://mikkun.site), Prince Mikael O.
Sabdullah’s creative portfolio.

The site is static HTML, CSS, and native JavaScript. Home links to WoodStones,
D’Basement, HANIYAH, and Side Quests. styles.css and script.js serve the homepage;
project-pages.css and project-pages.js serve the internal pages. interactions.css
and interactions.js provide shared motion; media.css and media.js provide
intentional video playback.

Required imagery, textures, and local fonts are in assets/. Optimized runtime
videos are MP4/H.264 with AAC audio and faststart in assets/videos/web/.
Original video masters and local QA material are excluded from publication.
The cleaned portrait is the approved production asset; its source remains local.

GitHub Pages publishes main; CNAME preserves the custom domain. Serve the root
with any static HTTP server for local development. Respect the approved
compositions, motion, responsive layouts, and reduced-motion behavior.
